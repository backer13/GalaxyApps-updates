# Сведения об обновлениях

Файл [versions.json](../versions.json) содержит только сведения о публичных релизах GalaxyBar и GalaxySplit.

| Поле | Назначение |
| --- | --- |
| `schemaVersion` | Версия формата данных. |
| `apps` | Записи приложений по Android package name. |
| `published` | Объявлен ли релиз пользователям. `false` не предлагает обновление. |
| `versionCode` | Целочисленный Android versionCode для сравнения с установленным приложением. |
| `versionName` | Номер версии, который видит пользователь. |
| `changes` | Основные изменения после предыдущего публичного релиза. |
| `telegramUrl` | Ссылка на релиз в Telegram. |
| `storeUrl` | Ссылка на SnickPro Store, если известна. |

## Правила публикации

- В файл попадают только опубликованные релизы. Наличие APK в закрытом архиве GitHub не означает публичный выпуск.
- Список изменений накапливается после предыдущего публичного релиза, включая промежуточные сборки. Для следующего GalaxyBar базовая версия — **1.54**.
- В список включаются изменения функций. Мелкие графические правки отдельно не перечисляются.
- Приложение проверяет версию и предлагает открыть Telegram или SnickPro Store. Автоматическая загрузка и установка APK не предусмотрены.
- Доступ к исходникам и архиву APK остаётся закрытым. Для публичного файла не нужны токены GitHub.
